# UnPlayer

在老师眼皮底下偷偷玩手机。你只有一只手能自由活动，而她的目光随时会转过来。

## 操作

| 按键 | 动作 |
|---|---|
| 按住鼠标左键 | 低头玩手机，进度推进 |
| 松开左键 | 抬头装乖，进度暂停 |
| R | 重开 |

## 核心规则

- 举着手机 = 100% 暴露；放下手机 = 0% 暴露
- **抬起和放下各有 0.35 秒过渡，过渡中暴露度 60%** —— 所以必须提前松手，不能等她转头
- 老师的注意值在被注视时上升、安全时下降，涨满即被抓
- 进度满即过关

## 运行

Godot 4.7（Forward+），直接用编辑器打开本目录，F5 运行。
